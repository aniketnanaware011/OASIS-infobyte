To-Do List Web Application
This is a simple and interactive To-Do List Web Application developed as part of the Level 2 Task for the OASIS INFOBYTE Web Development & Designing Internship.

The application allows users to add daily tasks with a title and description, view them in a list, and delete tasks when completed.

✅ Features
Add tasks with Title and Description
Display tasks in a structured list
Delete tasks easily
Clean and user-friendly interface
Responsive layout inspired by a professional dashboard UI

🛠️ Technologies Used
HTML – Page structure
CSS – Styling and layout
JavaScript – Task management and DOM manipulation

📁 Project Structure
ToDo-App ├── index.html ├── style.css └── script.js

📌 How to Run Locally
Download or clone the repository
Open the project folder
Double-click index.html
The To-Do App will open in your browser
