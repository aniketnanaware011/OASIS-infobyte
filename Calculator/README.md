
# Calculator Web Application

This is a simple and interactive **Calculator Web Application** developed as part of the **Level 2 Task** for the **OASIS INFOBYTE Web Development & Designing Internship**.

The calculator performs basic arithmetic operations with a clean and user-friendly interface.

---

## 🔢 Features

- Addition, Subtraction, Multiplication, Division
- Clear (C) and Backspace (⌫) functionality
- Responsive and modern UI
- Real-time input display
- Error handling for invalid expressions

---

## 🛠️ Technologies Used

- **HTML** – Structure of the calculator
- **CSS** – Styling and layout using Grid
- **JavaScript** – Calculator logic and interactivity

---

## 📁 Project Structure
Calculator-Oasis-Infobyte
└── Calculator
├── index.html
├── style.css
└── script.js


## 📌 How to Run Locally

1. Download or clone the repository  
2. Open the `Calculator` folder  
3. Double-click `index.html`  
4. The calculator will open in your browser
