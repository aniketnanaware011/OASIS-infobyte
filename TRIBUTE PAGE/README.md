# Tribute Page – Dr. A. P. J. Abdul Kalam

This is a **Tribute Page** created as part of the **Level 2 Task** for the **OASIS INFOBYTE Web Development & Designing Internship**.  
The page is dedicated to **Dr. A. P. J. Abdul Kalam**, honoring his life, achievements, and inspirational thoughts.

---

## 🌟 About the Project

The tribute page presents a clean and elegant layout showcasing:
- A brief introduction
- Major achievements
- A famous inspirational quote

The project focuses on **HTML and CSS fundamentals**, layout design, and visual presentation.

---

## ✨ Features

- Clean and responsive design
- Image with proper alignment
- Biography and achievements section
- Quote section with styled blockquote
- Simple and readable UI

---

## 🛠️ Technologies Used

- **HTML** – Structure of the webpage  
- **CSS** – Styling, layout, and visual design
